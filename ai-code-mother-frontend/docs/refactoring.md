# 架构重构交付说明

本轮在原有工作区重构之上继续实现。应用编辑现已统一为 features/app-management 下的弹窗，由首页和管理列表复用，保存后保留原页面的分页和筛选；原独立编辑页、编辑控制器和编辑路由已移除。没有修改 src/api 中任何文件，新增了原始文件集合及 SHA-256 检查。

后续按要求恢复了原始 `vite.config.ts`。当前通过 `scripts/dev.ts` 独立启动预览网关，主站仍使用原始 Vite 配置；生产预览脚本使用 `npm run build:preview` 单独生成。分页适配现已兼容后端字符串计数，修复首次提示词没有触发生成的问题；Vue 预览优先使用已发布目录，兼容旧 dist 路径。当前测试范围与启动方式以 README 为准，以下保留原重构交付记录。

## P0

1. **P0-01**：导航登录命令、原生测试 runner 的别名/TS 编译、Lint 错误已修复。测试源代码加入类型检查。
2. **P0-02**：页面和领域模型使用字符串 ID；生成 API 的 number 类型仅在外部适配层兼容。请求不做数字转换，响应拒绝已损失精度的数字；DTO 通过显式字段白名单映射。
3. **P0-03**：父页面不访问 iframe DOM，跨源编辑桥和静态专用网关已实现；主站阻止生成 HTML 的静态路径。生产需部署网关、TLS 和独立凭据域，参考 README 与 deploy/nginx.conf.example。
4. **P0-04**：初始化共享 Promise、会话版本失效、网络失败状态、公共路由降级、过期事件和退出失败处理已实现。
5. **P0-05**：生产 API 默认 /api，不再构造 localhost 后端地址；预览缺少独立 origin 时安全降级。登录回跳统一为站内路由，兼容旧的同源绝对地址。

## P1

6. **P1-06**：生命周期集中于 src/app/useController.ts，各 Controller 使用 start/dispose；构造函数不再读取路由/Store 或注册 Vue 生命周期。
7. **P1-07**：Controller 接收窄 API 端口、会话、路由、通知与确认依赖。生成/历史服务不依赖 UI 库或 DOM。
8. **P1-08**：命令拥有状态，对外公开只读 Ref；模板不访问私有 Store，跨控制器分页修改改为 owner 命令。表单草稿保留受控写入口。
9. **P1-09**：跨 feature 经公开入口或 api/components 子入口访问；编辑选择信息移到中立领域类型；架构检查阻止新增内部引用和导入环。
10. **P1-10**：DTO 映射、字符串 ID、业务错误适配已投入实际调用。移除了未使用的 AppWorkbenchContext、ChatSessionPort、PreviewPort 等声明。
11. **P1-11**：列表、编辑、会话和预览使用取消/版本检查；编辑弹窗监听显隐、目标和登录会话；写操作完成时检查页面存活及目标。取消不会宣称撤销已发生的服务端写入。
12. **P1-12**：权限策略集中生成、编辑、删除、部署、下载及历史能力，保持原有管理员/所有者产品规则；角色和精选优先级成为共享常量。
13. **P1-13**：流结束立即释放生成态，预览独立检查、有超时且刷新可取消；新生成资源的短暂 404 有有限重试。
14. **P1-14**：Axios/SSE/下载共享认证失效和业务错误语义；增加 SSE 空闲超时、断流检测、事件大小与 query 长度上限，保留已有 GET 协议。POST 流需要服务端配套，未擅自改协议。
15. **P1-15**：加入行为回归、架构/生成文件保护、包体积预算及根目录 GitHub Actions。CI 配置已落地，本轮没有运行远端 CI。
16. **P1-16**：Enter 发送尊重组合输入状态与 229 键码，Shift+Enter 保持换行。
